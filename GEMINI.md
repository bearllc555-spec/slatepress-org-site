# Project Instructions: slatepress.org

## Project Goal

slatepress.org is a defensive brand property in the SlatePress ecosystem. It displays a brief message and redirects visitors to slatepress.co.

## Tech Stack

- **Frontend:** Static HTML (index.html), Inter font
- **Icons:** SVG favicon
- **Deployment:** GitHub Actions → Cloudflare Pages

## Conventions

- **Branding:** SlatePress (`SLATE\PRESS`, blue `#2563EB`)
- **Robots:** `noindex,nofollow` (defensive property, not SEO target)
- **Versioning:** Track via git / deployment, not on-page label
